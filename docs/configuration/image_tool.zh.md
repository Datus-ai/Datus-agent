# 读图

直接让 Agent 查看本地截图、图表、表格、流程图或照片：

```text
读取 images/dashboard.png，解释图表的含义。
```

Agent 会调用 `filesystem_tools.read_image(path)`，将图片发送给当前选择的模型，无需单独配置视觉模型或 API Key。Datus 不提前判断模型能力。模型拒绝图片输入时，沿用现有模型错误处理，保留图片工具结果和对话历史。继续使用同一个模型时，后续请求可能再次报错；可以切换支持图片的模型，或新建会话。

## 工具与权限

`read_image` 属于 filesystem 工具组，沿用 `read_file` 的路径权限，支持相对于项目根目录的路径和绝对路径。如果 Agent 配置了明确的工具列表，需要包含 `filesystem_tools.read_image` 或 `filesystem_tools.*`。

文件必须位于运行 Agent 的机器上。此工具不负责附件上传、剪贴板读取或图片 URL 下载。

## 支持范围

| 项目 | 限制 |
|---|---|
| 格式 | 静态 PNG、JPEG、WebP，按实际文件内容校验 |
| 原文件大小 | 10 MiB |
| 原图像素数 | 2500 万像素 |
| 发送给模型的图片 | 自动纠正方向，最长边不超过 2048 像素 |
| 编码后图片大小 | base64 编码前不超过 3 MiB，必要时继续缩小 |

动画、PDF、SVG、损坏文件和超过上述限制的文件会返回工具错误。原文件不会被修改。缩图可能影响小字辨识，必要时可将关注区域裁成单独图片。

## 对话记录

图片会保存在本地会话数据库中，供后续追问和会话恢复使用。上下文压缩时，较旧的图片可能被替换为保留来源路径的标记；只要原文件仍存在，Agent 就可以再次调用 `read_image`。CLI、导出的对话文本、日志和 Trace 只保留图片元数据或省略标记，不包含图片数据。
