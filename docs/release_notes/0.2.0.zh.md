# 0.2.0

**增强的 Chat 功能**

- 高级多轮对话，提供顺畅的交互体验。[#91](https://github.com/Datus-ai/Datus-agent/issues/91)
- 数据库工具与文件系统操作的 agentic 执行，并自动生成待办列表。
- 支持自动与手动压缩（`.compact`）。[#125](https://github.com/Datus-ai/Datus-agent/issues/125)
- 通过 `.resume` 与 `.clear` 命令进行会话管理。
- 通过 `@table`、`@file`、`@metrics`、`@sql_history` 命令注入专属上下文。[#134](https://github.com/Datus-ai/Datus-agent/issues/134) [#152](https://github.com/Datus-ai/Datus-agent/issues/152)
- Token 消耗追踪与估算，提供更直观的资源可见性。[#119](https://github.com/Datus-ai/Datus-agent/issues/119)
- 在执行敏感工具操作前进行写权限确认。
- Plan Mode：AI 辅助的规划功能，可生成与管理待办列表。[#147](https://github.com/Datus-ai/Datus-agent/issues/147)

**自动化知识库构建**

- 从历史成功案例自动生成 MetricFlow 格式的 Metric YAML 文件。[#10](https://github.com/Datus-ai/Datus-agent/issues/10)
- 自动总结并标注工作区中 *.sql 文件，生成 SQL 历史记录文件。[#132](https://github.com/Datus-ai/Datus-agent/issues/132)
- 借助 metrics 与 SQL 历史，提高 SQL 准确性与生成速度。

**MCP 扩展**

- 新增 `.mcp` 命令，可添加、移除、列出与调用 MCP Server 与工具。[#54](https://github.com/Datus-ai/Datus-agent/issues/54)

**灵活的工作流配置**

- 通过 `agent.yml` 完全自定义工作流定义。
- 可配置节点、模型与数据库连接。
- 支持子工作流与结果选择，以提升准确性。[#88](https://github.com/Datus-ai/Datus-agent/issues/88)

**上下文探索**

- 改进 `@catalog`，可跨多个数据库展示所有数据库、Schema 与表。
- 新增 `@subject`，展示由 MetricFlow 构建的全部指标。[#165](https://github.com/Datus-ai/Datus-agent/issues/165)
- 集成上下文检索工具，提升元数据与指标的召回率。[#138](https://github.com/Datus-ai/Datus-agent/issues/138)

**用户行为日志**

- 自动收集用户行为日志。
- 将人机交互数据转化为可训练数据集，用于未来改进。
