# 0.2.5

**新功能**

- **OpenAI Agent SDK 0.7.0 升级，支持 Kimi-2.5 与 Gemini-3** - 通过 `litellm_adapter` 与 `sdk_patches` 重构模型层，无缝接入最新 Kimi-2.5 与 Gemini-3 系列模型。
- **AgentSkills 支持** - 引入完整的 Skill 体系，包括 Skill 配置、注册、管理与权限控制，同时支持 bash 与函数式 Skill 工具。[docs](https://docs.datus.ai/integration/skills/)
- **Tools as MCP Server** - 将 Datus 数据库工具与上下文检索能力暴露为 MCP Server，可与 Claude Desktop、Claude Code 等 MCP 兼容客户端集成。[docs](https://docs.datus.ai/integration/mcp/)

**增强**

- **知识生成迭代** - 优化外部知识节点，提升知识存储与上下文检索的准确性。[docs](https://docs.datus.ai/knowledge_base/ext_knowledge/)
- **Semantic Tools 优化** - 优化语义工具与上下文检索，使 CLI 中结果更快、更相关。
- **生成 Prompt 字符串校验** - 加强多个 Prompt 模板中的字符串校验，提升生成结果的可靠性。
- **基于 Action 的用户交互模型** - 重新设计 CLI 交互层，统一执行、生成与规划的 Action 模型。
- **Reference SQL 并行化与日期支持** - 并行化 reference SQL 初始化以加速启动，并增强日期表达式解析。[docs](https://docs.datus.ai/knowledge_base/reference_sql/)
- **Bootstrap Markdown 摘要** - Bootstrap 完成后展示格式化 Markdown 摘要，便于快速回顾生成结果。[docs](https://docs.datus.ai/getting_started/dashboard_copilot/)
- **Subject 条目删除** - 支持直接在 `@subject` 屏幕中删除语义模型、指标与 SQL Summary。[docs](https://docs.datus.ai/cli/context_command/#subject)

**Bug 修复**

- **Subject Node 竞争条件** - 修复并行创建多个 subject 节点时的竞争条件，提升并发安全性。
- **多轮 Benchmark 评测** - 修复多轮评测时 Agent 状态、工作流执行器与配置处理的相关问题。[docs](https://docs.datus.ai/benchmark/benchmark_manual/)
- **归因分析** - 简化归因分析逻辑，使结果更清晰可靠。
