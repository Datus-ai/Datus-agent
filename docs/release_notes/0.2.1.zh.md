# 0.2.1

**新功能**

- **Web Chatbot 升级** - 新增反馈收集、问题上报、流式输出，以及用于嵌入的 `&hide_sidebar=true` 参数。[docs](https://docs.datus.ai/web_chatbot/introduction/)
- **上下文生成命令** - 在 Subagent 中新增 `/gen_semantic_model`、`/gen_metrics`、`/gen_sql_summary` 命令，支持知识库的动态扩充。[#192](https://github.com/Datus-ai/Datus-agent/issues/192) [docs](https://docs.datus.ai/subagent/builtin_subagents/)
- **交互式上下文编辑** - `@catalog` 与 `@subject` 命令支持可视化编辑，可修改语义模型、指标与 SQL Summary。[#219](https://github.com/Datus-ai/Datus-agent/issues/219) [#199](https://github.com/Datus-ai/Datus-agent/issues/199) [#175](https://github.com/Datus-ai/Datus-agent/issues/175) [docs](https://docs.datus.ai/cli/context_command/#subject)
- **Scoped 知识库** - Subagent 现支持 scoped KB 初始化，便于上下文隔离与管理。[#217](https://github.com/Datus-ai/Datus-agent/issues/217)

**增强**

- **MetricFlow 集成** - 从 `env_settings.yml` 加载配置，改进项目检测，并优化输出格式。[#214](https://github.com/Datus-ai/Datus-agent/issues/214) [#216](https://github.com/Datus-ai/Datus-agent/issues/216) [docs](https://docs.datus.ai/metricflow/introduction/)
- **灵活的模型配置** - Agent 配置支持多模型提供方与多规格模型。[#195](https://github.com/Datus-ai/Datus-agent/issues/195)
- **CLI 展示改进** - 增强表格宽度渲染，使 SQL 查询结果更易读。[#200](https://github.com/Datus-ai/Datus-agent/issues/200)
- **改进的初始化** - `datus-agent init` 命令的错误处理与初始化流程更友好。[#194](https://github.com/Datus-ai/Datus-agent/issues/194)

**依赖变更**

- `openai-agents` 升级至 0.3.2（需手动更新：`pip install -U openai-agents`）
- `datus-metricflow` 更新至 0.1.2
