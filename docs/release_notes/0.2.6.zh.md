# 0.2.6

**新功能**

- **Ask User 工具** - 引入交互式 `ask_user` 工具，支持内联自由文本输入和批量提问，集成到 GenSQL 与 GenReport 节点，实现人机协同（human-in-the-loop）工作流。[#457](https://github.com/Datus-ai/Datus-agent/pull/457) [#460](https://github.com/Datus-ai/Datus-agent/pull/460) [#481](https://github.com/Datus-ai/Datus-agent/pull/481)
- **Skill 市场 CLI** - 内置市场，可直接在 CLI 中发现、安装与管理社区 Skill。[#416](https://github.com/Datus-ai/Datus-agent/pull/416) [docs](https://docs.datus.ai/integration/skills/)
- **通用 Chat Agent** - 通用对话 Agent，支持 SQL 生成之外的灵活对话工作流。[#452](https://github.com/Datus-ai/Datus-agent/pull/452)
- **Explore Task 工具** - 用于在 Agent 内浏览与管理任务的探索工具。[#455](https://github.com/Datus-ai/Datus-agent/pull/455)
- **Storage Adapter** - 可插拔的存储适配层，支持灵活的后端集成。[#446](https://github.com/Datus-ai/Datus-agent/pull/446)
- **4 个新数据库适配器** - 在 [datus-db-adapters](https://github.com/Datus-ai/datus-db-adapters) 仓库新增 ClickHouse、Hive、Spark、Trino 四个适配器，均可作为独立包安装：`pip install datus-<database>`。[docs](https://docs.datus.ai/adapters/db_adapters/)

**增强**

- **会话恢复 / 回退** - 新增 `.resume`、`.rewind`、`.interrupt` 命令，支持方向键交互式选择，便于浏览历史会话。[#438](https://github.com/Datus-ai/Datus-agent/pull/438) [#470](https://github.com/Datus-ai/Datus-agent/pull/470) [docs](https://docs.datus.ai/cli/chat_command/)
- **Scoped 上下文过滤** - 基于过滤器的 scoped 上下文，使 SQL 生成时的知识检索更精准。[#441](https://github.com/Datus-ai/Datus-agent/pull/441)
- **Subagent 直连 Web** - 新增 `--subagent` CLI 参数，可直接通过 Web 界面启动 Subagent。[#447](https://github.com/Datus-ai/Datus-agent/pull/447)
- **CLI 交互体验** - 改进多行输入支持与省略号截断，提升可读性。[#468](https://github.com/Datus-ai/Datus-agent/pull/468)
- **简化 Subagent 指引** - 精简 Subagent 使用说明，使上手流程更清晰。[#469](https://github.com/Datus-ai/Datus-agent/pull/469)
- **加固 Function Tools** - 强制只读 SQL 执行，工具注册去重，并完善 docstring。[#474](https://github.com/Datus-ai/Datus-agent/pull/474)
- **当前日期注入** - 直接将 `current_date` 注入系统 prompt，移除独立的 `get_current_date` 工具。[#473](https://github.com/Datus-ai/Datus-agent/pull/473)
- **数据压缩** - 为 `query_metrics` 增加响应压缩，并修复 `DataCompressor` 的 model_name 处理，降低 token 消耗。[#435](https://github.com/Datus-ai/Datus-agent/pull/435) [#472](https://github.com/Datus-ai/Datus-agent/pull/472)

**Bug 修复**

- **Kimi-K2.5 与 Qwen3-Coder-Plus 初始化** - 修复交互式初始化时这些模型对 temperature/top_p 的支持。[#483](https://github.com/Datus-ai/Datus-agent/pull/483)
- **生成 Hooks 条件** - 修复 `generation_hooks` 使用错误 `where` 表达式条件的问题。[#482](https://github.com/Datus-ai/Datus-agent/pull/482)
- **Ctrl+O 切换** - 修复使用 Ctrl+O 切换时之前轮次响应未显示的问题。[#477](https://github.com/Datus-ai/Datus-agent/pull/477)
- **缺失 Tabulate 依赖** - 在 pyproject.toml 与 requirements.txt 中补齐 `tabulate` 依赖。[#476](https://github.com/Datus-ai/Datus-agent/pull/476)
- **Skill 扫描路径** - 从默认扫描路径中移除 `~/.claude/skills`，并优化 ChatAgenticNode 的配置传递。[#475](https://github.com/Datus-ai/Datus-agent/pull/475)

**文档**
