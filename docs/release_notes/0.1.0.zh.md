# 0.1.0

**Datus-cli**

- 支持连接 SQLite、DuckDB、StarRocks 与 Snowflake，并支持常用命令行操作。
- 支持三类命令扩展：`!run_command`、`@context` 与 `/chat`，提升开发效率。

**Datus-agent**

- 支持基于 React 范式的自动 NL2SQL 生成。
- 支持获取数据库元数据并基于元数据构建向量检索。
- 通过 MCP Server 支持深度推理。
- 支持与 bird-dev 和 spider2-snow benchmark 的集成。
- 支持工作流的保存与恢复，可记录执行上下文与节点的输入/输出。
- 提供灵活配置：可在 Agent.yaml 中定义多模型、多数据库与节点执行策略。
